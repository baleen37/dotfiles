# Triage labels

| 역할            | GitHub 라벨     | 의미                 |
| --------------- | --------------- | -------------------- |
| needs-triage    | needs-triage    | 유지관리자 검토 필요 |
| needs-info      | needs-info      | 추가 정보 대기       |
| ready-for-agent | ready-for-agent | 에이전트 구현 가능   |
| ready-for-human | ready-for-human | 사람의 구현 필요     |
| wontfix         | wontfix         | 진행하지 않음        |

이슈 분류 시 이 매핑을 사용한다.
