# Issue tracker: GitHub

이슈와 스펙은 baleen37/dotfiles의 GitHub Issues에서 관리한다.
작업에는 gh CLI를 사용한다.

- 생성: gh issue create --repo baleen37/dotfiles --title "..." --body-file <file>
- 조회: gh issue view <number> --repo baleen37/dotfiles
- 목록: gh issue list --repo baleen37/dotfiles
- 분류 라벨: docs/agents/triage-labels.md 참조

PRs as a request surface: no.
