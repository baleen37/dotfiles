# ADR 0006: 하나의 설정 소스로 Debian 사용자 환경과 네이티브 서비스를 순차 적용한다

- 상태: 채택
- 날짜: 2026-11-15
- 대체 범위: ADR 0004의 Debian 분기·검증 계약. 기존 CLI 인자 제한과 identity 필수 정책은 유지한다.

Debian도 Nix/Home Manager로 사용자 환경을 관리하며, 네이티브 APT·서비스 실행은
동일한 필터링된 설정 소스에서 수행한다. 정상 switch는 두 영역의 identity·복호화·
준비 상태를 먼저 확인한 뒤 Home Manager와 네이티브 서비스를 순서대로 적용하고,
후속 실패에는 완료 단계와 부분 적용 가능성을 표시하며 자동 롤백을 시도하지 않는다.
`--build`는 키 없이 HM 빌드와 네이티브 선언 검증만 수행하고, `just` 명령은 기존
bootstrap/switch 진입점에 위임한다.
